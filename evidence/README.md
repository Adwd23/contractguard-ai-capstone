# Executed Evidence

This directory is intentionally committed because the capstone rubric requires captured
outputs rather than code-only claims.

## Core committed evidence

- `01_prompt_injection_blocked.json` — real indirect attack blocked before any tool call.
- `02_low_risk_completed.json` — autonomous completed path and schema-routed functions.
- `03_high_risk_paused_for_human.json` — function retry, Reflexion, risk routing, and HITL
  pause.
- `03_high_risk_checkpoint_history_before_restart.json` — ordered pre-restart checkpoints.
- `04_checkpoint_loaded_after_restart.json` — paused state loaded by a new service object.
- `05_high_risk_resumed_and_completed.json` — human resume, report revision, PII masking,
  and final artifact.
- `05_high_risk_checkpoint_history_after_resume.json` — complete ordered history.
- `graph_spec.json` — framework package/version, nodes, edges, conditions, branches,
  cycles, and termination controls.
- `execution_log.jsonl` — structured node, function, agent, failure, security, checkpoint,
  latency, and HITL events.
- `metrics_before_restart.prom` and `metrics_after_restart.prom` — Prometheus snapshots.
- `artifacts/` — generated Markdown reports and JSON metadata.
- `pytest_results.txt` — automated regression-test output.
- `run_summary.json` — hard-asserted evaluator proof flags.
- `prepublish_report.json` — final repository-readiness checks.

`checkpoints.sqlite` is generated locally and excluded from Git because it is mutable. The
JSON checkpoint snapshots and histories provide reviewable evidence while the demo itself
proves the real SQLite restart path.

## Optional/generated evidence

- `06_live_llm_function_call.json` is created only after a real Gemini, OpenRouter, or
  Groq native function call.
- `07_minio_docker_smoke.json` is generated by the Docker/MinIO CI job after it verifies
  report and metadata objects through the MinIO SDK.
