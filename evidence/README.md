# Runtime Evidence

This directory contains committed execution evidence for ContractGuard AI v1.3.1. The evidence can be reproduced without GitHub Actions.

Run the complete demonstration and rebuild the executed notebook:

```bash
python scripts/run_capstone_demo.py
python scripts/build_executed_notebook.py
python scripts/runtime_grader_probe.py --refresh
python scripts/prepublish_check.py --skip-runtime
```

Or run the complete validation pipeline in one command:

```bash
python scripts/prepublish_check.py
```

## Main evidence files

- `run_summary.json` — machine-readable end-to-end rubric assertions.
- `graph_spec.json` — real LangGraph nodes, conditional routing, loops, checkpointer, and HITL APIs.
- `01_prompt_injection_blocked.json` — actual attack blocked before any tool call.
- `02_low_risk_completed.json` — autonomous path with real schema-described functions.
- `03_high_risk_paused_for_human.json` — failed tool retry, Reflexion loop, and real HITL pause.
- `04_checkpoint_loaded_after_restart.json` — persisted LangGraph interrupt restored by a new service instance.
- `05_high_risk_resumed_and_completed.json` — `Command(resume=...)`, approval, output revision, PII masking, and completion.
- `07_minio_docker_smoke.json` — completed MinIO/S3 storage smoke verification through the S3 SDK.
- `execution_log.jsonl` — structured security, tool, retry, agent, and HITL events.
- `metrics_before_restart.prom` — captured Prometheus metrics.
- `pytest_results.txt` — captured regression-test output.
- `runtime_grader_probe.json` — strict one-object JSON runtime acceptance summary.
- `prepublish_report.json` — final post-runtime repository consistency audit.
- `local_static_validation.json` — final static repository audit.

`grader_manifest.json` mirrors the source-level evaluator map in root `EVALUATION.json`.

The core runtime scenario evidence is generated by the project scripts and should be reproduced rather than manually altered. The final audit reports document repository-level consistency checks performed after the runtime evidence was captured, including removal of the obsolete CI workflow and addition of the verified MinIO smoke artifact.
