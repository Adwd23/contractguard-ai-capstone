# v1.3 Trainer-Fix Verification

This document maps each trainer observation to executable source and a regression check.

## 1. Declared libraries are visibly used

- `uvicorn` is imported and called in `src/contractguard/server.py`.
- `ipykernel` is imported by `scripts/build_executed_notebook.py` and its version is printed inside the executed notebook.
- Regression: `test_declared_runtime_libraries_are_directly_used`.

## 2. Guardrails are enforcement code

- `InputGuardrail.enforce()` calls the detector and raises `GuardrailViolation` on an attack.
- `InputSecurityAgent.run()` calls that method before the document/tool nodes.
- `OutputGuardianAgent.run()` calls `OutputGuardrail.enforce()` before artifact storage.
- Runtime evidence asserts the blocked attack produced zero tool calls.
- Regression: `test_guardrails_are_enforced_in_executable_code`.

## 3. The graph has explicit conditional edges

`src/contractguard/workflow.py` creates `StateGraph(AuditState)` and contains five `add_conditional_edges(...)` calls. The policy-search branch has a real self-loop; the quality branch can return to research; the output branch can return to report generation.

Regression: `test_real_langgraph_stategraph_has_explicit_conditional_edges`.

## 4. HITL pauses and resumes end to end

`human_approval` calls `interrupt(...)`. External approval uses:

```python
graph.invoke(Command(resume=request.model_dump(mode="json")), config=config)
```

The resumed node then returns `Command(goto="report_writer")` or `Command(goto="rejected")`. The evidence runner closes the original service, creates a new service using the same SQLite checkpoint, verifies the pending `human_approval` node, and resumes it.

Regression: `test_human_interrupt_has_command_resume_end_to_end` plus the workflow restart test.

## 5. Agents are independent specialist classes

The project has separate modules and classes for Coordinator, Document Analyst, Policy Research, Compliance Analyst, Quality Reviewer, Security Reviewer, Report Writer, Output Guardian, and Artifact Storage. They exchange structured `AgentMessage` records in shared state and use separate tool allow-lists.

Regression: `test_multiple_agents_are_real_classes_in_separate_modules`.

## 7. JSON grading stability

`prepublish_check.py` parses every top-level evidence JSON file. Invalid JSON makes the publication gate fail. Runtime evidence is regenerated by CI from the current code rather than hand-edited.
